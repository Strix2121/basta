# بسطة — منصة سورية للبيع والشراء

نموذج أولي (Demo) لموقع سوري متعدد الأقسام: متجر إلكتروني، سوق بيع بين المستخدمين، عقارات، وسيارات.

⚠️ هذا نموذج تجريبي (Frontend فقط) بدون قاعدة بيانات أو باك-إند حقيقي. كل البيانات ثابتة داخل الكود لأغراض العرض.

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | الموقع الرئيسي (المتجر + سوق الاستخدام + عقارات + سيارات) |
| `basta-dashboard.html` | لوحة تحكم البائع (إدارة الإعلانات، إضافة إعلان، رسائل) |
| `admin.html` | لوحة تحكم الأدمن، محمية بكلمة سر تجريبية: `basta2026` |
| `css/index.css`, `css/basta-dashboard.css`, `css/admin.css` | تنسيقات كل صفحة على حدة |
| `js/index.js`, `js/basta-dashboard.js`, `js/admin.js` | منطق كل صفحة على حدة |

## التشغيل محلياً

فقط افتح `index.html` بأي متصفح، ما يحتاج أي تثبيت.

## النشر على GitHub Pages

شوف قسم "خطوات الرفع" اللي أرسله معك بالمحادثة، أو ببساطة:
1. ارفع هذا المجلد لمستودع (repository) على GitHub
2. من إعدادات المستودع → Pages → فعّل النشر من فرع `main`
3. الموقع رح يصير متاح على رابط من نوع `username.github.io/repo-name`

## ملاحظة أمان مهمة

كلمة سر لوحة الأدمن مكتوبة حالياً داخل كود الصفحة (`admin.html`) وهذا **غير آمن لموقع حقيقي** — أي شخص يقدر يفتح كود الصفحة ويشوفها. لموقع فعلي، لازم:
- تسجيل الدخول يتحقق من كلمة السر على سيرفر (باك-إند)، مو بالمتصفح
- استخدام تشفير لكلمات السر (hashing) وقاعدة بيانات مستخدمين حقيقية
- استخدام HTTPS دائماً

## الخطوات التالية لموقع حقيقي

- بناء باك-إند (Node.js / Laravel / Django) وقاعدة بيانات
- نظام تسجيل دخول حقيقي بصلاحيات (مستخدم / بائع / أدمن)
- رفع صور فعلي وتخزينها (مثل AWS S3 أو Cloudinary)
- نظام دفع أو "الدفع عند الاستلام"
